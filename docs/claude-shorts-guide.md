# 고니 | Claude로 숏폼 만드는 방법

> 실제 제작 사례: ESR 할로락 클래식 맥세이프 케이스 + 강화유리 1매 세트. 2026년 10월 8일 Claude Opus 5.5에서 제품 사진 두 장으로 20초짜리 9:16 광고 영상을 만들었다. 이 문서는 실제로 보낸 지시문, 결과물, 다시 만드는 순서를 기록한다.

수강생은 먼저 [고니 GitHub 저장소](https://github.com/qwer777qq/goni-opus55-shorts-skill)의 [시작 안내](../STUDENT_START.md)를 따라 스킬을 설치한다.

## 무엇을 준비하나

1. **상품 링크와 원본 이미지**: 상품명, 옵션, 구성품이 보이는 공식 판매 페이지를 준비한다. 이 사례에서는 [ESR 공식 판매 페이지](https://brand.naver.com/esr/products/13736838915)의 이미지 두 장을 Claude 채팅에 첨부했다.
2. **영상 조건**: 길이 20초, 세로 9:16, 한국어 TTS, 자막, MP4, 편집 가능한 소스를 요청했다.
3. **표현 범위**: 실제 사진과 다른 제품 외형을 만들지 않고, 판매 페이지에서 검증되지 않은 성능·가격·배송 문구를 쓰지 않도록 했다.

## Claude에 실제로 보낸 첫 지시문

아래는 첫 제작 요청의 원문이다. 상품 링크와 이미지만 바꾸면 다른 제품에도 응용할 수 있다.

```text
첨부한 두 이미지는 네이버 ESR 공식 판매 페이지의 실제 상품 이미지입니다. 상품: ESR 할로락 클래식 맥세이프 케이스 + 강화유리 1매 SET, 클리어, 아이폰 18 프로. 원본 링크: https://brand.naver.com/esr/products/13736838915

이 상품을 구매하고 싶어지는 20초짜리 9:16 한국어 숏츠 광고로 실제 제작해 주세요. 목표는 실사 스튜디오에서 제품을 촬영한 듯한 고급 모션그래픽입니다. 제품 외형, 맥세이프 링, 카메라 홀, 투명 재질은 첨부 사진과 일치시켜 주세요. 첨부 사진을 바탕으로 깊이감 있는 2.5D 연출, 정교한 마스킹, 카메라 돌리/패럴랙스, 실제 같은 반사광과 그림자, 자연스러운 모션 블러를 사용하세요. 손으로 착용하는 실사 장면을 억지로 생성하지 말고, 제품 사진을 활용한 스튜디오 광고 연출에 집중하세요.

후킹은 '새 아이폰, 케이스와 필름 따로 고르세요?'처럼 구매자의 번거로움에서 시작하고, 투명 디자인→맥세이프 케이스→강화유리 1매 포함→세트 구성의 순서로 보여 주세요. 한국어 TTS 여성 또는 중성 톤으로 자연스럽게 읽고, 자막과 화면 전환을 TTS에 맞춰 주세요. 가격·할인·배송일은 변동되므로 영상에 넣지 마세요. 상품 페이지에서 확인되지 않은 낙하 성능, 자력 수치, 완전한 황변 방지 등의 주장은 넣지 마세요.

바로 제작을 진행해 주세요. 먼저 20초 타임라인과 TTS 대본을 짧게 제시하고, 이어서 여기서 가능한 방식으로 재생 가능한 미리보기와 편집 가능한 소스, 가능하면 1080×1920 MP4와 TTS 음성 파일까지 만들어 주세요. 이 채팅에서 MP4 렌더링이나 음성 생성이 불가능하다면 가능한 산출물을 먼저 완성하고, 어떤 단계가 남았는지 정확히 알려 주세요. 기획만 제시하고 멈추지 마세요.
```

## 실제 제작 흐름

| 구간 | 화면에서 강조한 내용 | TTS 핵심 문장 |
| --- | --- | --- |
| 0~3.6초 | 케이스와 필름을 분리해서 보여 주는 훅 | 새 아이폰, 케이스랑 필름 따로 고르세요? |
| 3.6~8초 | 투명 디자인과 제품 전체 | 투명한 클리어 디자인으로, 아이폰 본래 색감을 살려 줘요. |
| 8~12.4초 | 맥세이프 링과 카메라 주변 클로즈업 | 맥세이프 링을 더한 케이스에, 카메라 주변까지 깔끔하게. |
| 12.4~16초 | 강화유리 필름 | 강화유리 필름 한 장도 함께 들어 있어요. |
| 16~20초 | 케이스 + 강화유리 세트 엔드카드 | 케이스와 필름을 한 번에. ESR 할로락 클래식 세트. |

Claude는 공식 상품 사진에서 제품을 분리해 레이어로 만들고, 확대·패닝·빛 반사·그림자·자막 애니메이션을 더했다. 한국어 TTS와 배경음악을 합쳐 최종 영상을 출력했다. 이는 **실사 촬영본이 아니라 상품 사진을 이용한 2.5D 모션그래픽**이다.

## 제작 중 보낸 수정 지시문

첫 렌더 대기 명령이 자기 자신을 계속 감지할 수 있는 상태여서 아래 지시를 추가로 보냈다. 영상 생성이 오래 멈춰 보일 때는 산출 파일과 실제 렌더 프로세스를 확인하도록 요청하는 것이 핵심이다.

```text
렌더 대기 명령의 pgrep -f "python3 render.py"는 그 문자열이 들어간 현재 bash 명령 자체를 잡아 무한 루프가 될 수 있습니다. 현재 대기 도구 실행을 멈추고 render.log와 실제 렌더 프로세스/PID를 확인해 주세요. 렌더가 끝났다면 즉시 ffmpeg로 음성을 합쳐 최종 MP4를 만들고, SRT·TTS WAV·편집 소스를 묶어 다운로드 가능한 파일로 전달해 주세요. 방금 Claude Skills에 설치한 opus55-motion-graphics 스킬도 확인해 관련 레퍼런스를 고르되, 우선 지금 영상 완성부터 진행해 주세요.
```

Claude는 실제 PID로 렌더 완료를 확인했고, 처음 만든 음성의 발음이 뭉개져 한국어 여성 음성으로 다시 합성했다. '1매'가 부정확하게 읽혀 내레이션과 자막에서는 '한 장'으로 바꿨다.

## 받은 결과물과 검수

- 최종 영상: `ESR_halolock_shorts_1080x1920.mp4` — H.264 영상 + AAC 오디오, 1080×1920, 30fps, 20초.
- 보조 파일: TTS 단독 WAV, 최종 음향 믹스 WAV, SRT 자막, 렌더 코드·제품 분리 레이어·대본·줄별 음성이 들어 있는 편집 소스 ZIP. 수강생은 자신의 Claude 채팅에서 이 파일들이 실제로 생성되고 다운로드되는지 확인한다.
- 검수 결과: 영상의 1·5·9·13·17·19초 화면을 확인했고, MP4의 길이·해상도·오디오 트랙을 검사했다. 제품 구성과 엔드카드가 보인다.
- 한계: 약 8~12초 클로즈업은 원본 사진이 약 1000px여서 다소 부드럽다. 더 선명하게 만들려면 공식 고해상도 이미지를 넣고 다시 렌더한다.

## 깃허브 레퍼런스를 내 제작 스킬로 만든 과정

참고 저장소는 [yihui-dev/awesome-opus5-5-videos](https://github.com/yihui-dev/awesome-opus5-5-videos)이다. 2026년 10월 8일 `756290289742535eb0ac3817548f152e9759cc70` 커밋을 복제했다. 이 저장소의 영상 513개 **참고 목록과 프롬프트**를 검색 가능한 로컬 카탈로그로 정리했다. 저장소 자체가 모든 영상의 완성 소스 코드를 제공하는 것은 아니다.

그 자료를 바탕으로 `opus55-motion-graphics`라는 **개인용 제작 스킬**을 새로 작성했다. 스킬에는 레퍼런스 검색 스크립트, 제품 광고용 제작 절차, 실제 이미지와 광고 문구 검증, TTS·자막·MP4 출력 확인 기준이 들어 있다. Codex와 Claude Skills에 각각 설치했고, Claude가 이 스킬을 불러오는 것까지 확인했다. 이번 첫 영상은 스킬 설치 직전에 대부분 제작되어, 스킬에서 고른 레퍼런스는 다음 수정부터 반영할 수 있다.

원본 저장소는 MIT 라이선스다. 개인용으로 정리한 스킬에도 원본 링크와 라이선스를 보존했다. **내가 새로 만든 것은 제작 절차와 검색 도구이며, 원본 레퍼런스의 창작자를 내 것으로 표시하지 않는다.**

```text
먼저 타임라인과 TTS 대본을 간단히 보여 준 뒤 제작을 계속하세요. 최종 1080×1920 MP4, TTS 단독 WAV, SRT, 편집 가능한 소스를 제공하고 완성 영상을 실제로 검수하세요. 기획안만 제시하고 멈추지 마세요. 설치된 opus55-motion-graphics 스킬에서 제품 영상 레퍼런스를 최대 3개 골라 전환·타이포·카메라 움직임에 각각 어떻게 적용했는지 설명해 주세요.
```

## 업로드 전 마지막 확인

- 전체 영상을 소리와 함께 재생해 발음, 무음, 자막 싱크를 확인한다.
- 휴대전화 크기에서 첫 3초의 훅과 상품명이 읽히는지 본다.
- 실제 구성품과 다른 표현, 근거 없는 성능 주장, 오래된 가격·할인·배송 문구가 없는지 본다.
- MP4가 실제로 열리는지, 세로 해상도와 길이가 맞는지 확인한다.
- 공식 상품 이미지의 광고 사용 가능 범위와 게시 계정의 권리를 확인한 뒤 게시한다.
